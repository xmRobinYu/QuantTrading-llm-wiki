> 把课程里的基本面选股和因子分析部分压成一条连续研究线，从营收、利润、规模、价值、质量因子一路走到自定义因子与 Alpha013 实战。

## 背景与动机

这门课真正能和知识库现有主树形成互补的，不只是技术指标案例，更是它把“基本面量化选股”和“因子分析”连成了一段相对连续的入门路径。对初学者来说，这一段比单纯记住某个策略更重要，因为它解释了：

- 因子从哪里来
- 因子怎么分类
- 因子写出来后如何分析

### 这条线的结构

- `33-38`：告诉你哪些基本面或风格维度能成为选股因子
- `52-55`：告诉你怎么从“因子类别”走到“因子对象、结果展示与 Alpha 实战”

这意味着课程没有把选股因子和因子分析割裂开，而是先讲选股语义，再讲研究方法。

### 这条线最有价值的地方

- 让初学者知道因子不是凭空发明，而是和营收、利润、规模、价值、质量这类金融语义强绑定。
- 让“自定义因子”不再只是 API 用法，而能接回选股与 Alpha 的研究逻辑。
- 把课程里的因子章节变成知识库里可复用的研究桥梁层。

## 现状与趋势

这条线已经足够支撑“因子入门”层面的学习，但它仍然偏课程化。真正要变成长期知识资产，还需要进一步接入：

- 样本外验证
- 交易成本与换手
- 风险暴露剥离
- 实盘淘汰标准

这些都已经在知识库现有的概念页和综合分析页里具备更强表达，因此这条课程线最适合被当作“入门入口”，而不是最终答案。
