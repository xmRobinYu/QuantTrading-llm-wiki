> 把这门课里最偏工程实现的一组内容收束成一条平台脚手架线，帮助学习者快速理解聚宽式量化平台里的对象、函数和策略组织方式。

## 背景与动机

课程最容易被忽视、但长期最值钱的一段，不是后面的策略案例，而是平台脚手架这条线。因为很多初学者卡住的第一步不是“不懂均线”，而是“不知道量化平台脚本到底由哪些对象、函数和状态组成”。

把这条线单独抽出来，有两个价值：

- 帮助读者先建立运行时心智模型，再看策略
- 让课程里的工程资产能直接反查到知识库现有的 [[执行模型]]、[[投资组合构建]] 和 [[量化AI工作区模板]]

### 这条线真正讲了什么

- 平台层：量化交易不是裸 Python 脚本，而是运行在聚宽式量化平台之上的事件驱动环境。
- 框架层：一个最小策略至少要有初始化、定时/触发逻辑和交易动作。
- 对象层：`Context`、`Position`、`Portfolio`、`Order`、`Trade` 等对象构成了策略和账户状态的可观察面。
- 执行层：交易函数不是“发一个请求”这么简单，它决定了如何把信号变成真实持仓。

### 最值得保留的两个认知

- 量化策略的第一性问题，不是指标，而是运行时对象和策略骨架。
- 课程里的对象讲解，实际上是在教“量化平台 API 如何被组织成一套可运行系统”。

## 现状与趋势

这条线在课程里是典型的“脚手架层”内容。它不一定最容易让人觉得“学完就能赚钱”，但对于之后理解：

- 回测怎么驱动
- 交易函数如何落单
- 持仓与组合状态如何被读取

都有明显帮助。

如果后续知识库要把视频课程进一步压缩成工程手册，这条线最值得单独升级成“平台 API 与对象速查页”。
