> 本讲把价值类因子放回“价值投资”语境中理解，核心目标不是追热门股，而是用若干估值指标去找相对低估、主营业务与盈利质量更可接受的股票。

## 核心要点

- 课程把价值类因子定义为价值投资的量化化身，重点是寻找“当前股价相对低估”的股票，而不是单看价格绝对高低。
- 本讲反复强调三个常用指标：`PB`（市净率）、`PS`（市销率）、`PE`（市盈率），其中市盈率又区分动态与静态两种口径。
- 市净率低通常被视为更有投资价值，但讲师明确提醒它会受行业差异影响，不能脱离行业背景孤立使用。
- 市销率被课程用来辅助识别“利润看起来不错，但主营业务竞争力并不强”的公司，因此更偏向业务质量筛查。
- 代码实战不是单独用一个估值指标，而是把 `PB`、`PS`、动态/静态 `PE` 组合起来筛股票并排序。

## 详细笔记

### 价值类因子的定位

课程把价值类因子直接等同于“价值投资”的量化表达。它关注的是：

- 当前股价是否处于相对低位
- 账面价值、利润、股息、现金流能否支撑当前估值
- 公司是否只是表面便宜，还是基本面真的具备支撑

这一定义说明，本讲不是在讨论短线择时，而是在做基本面估值筛选。

### 三类核心估值指标

`PB`：市净率，公式是“每股市价 / 每股净资产”。讲师的口径是“通常越低越有价值”，但又补了两层限制：

- 不同行业的常态区间不同，传统行业与互联网行业不能直接横比。
- 过高可能意味着短期炒作和泡沫，过低也可能意味着公司本身质量一般。

`PS`：市销率，公式是“股价 / 每股销售额”。课程更看重它对主营业务质量的筛查能力，因为它能把“靠非经常性收益撑利润”的公司剔掉一部分。

`PE`：市盈率。本讲把它拆成两种：

- 静态市盈率：更靠近上一年已披露财报的利润口径。
- 动态市盈率：更靠近根据当年季报、半年报去推未来盈利的口径。

课程对这两者的区分重点不在精确会计定义，而在“一个偏已实现利润，一个偏未来预测利润”。

### 实战筛选思路

代码演示延续聚宽查询式写法，实际策略不是只看一个字段，而是组合过滤：

- 用较低 `PB` 挑估值不高的股票
- 用较低 `PS` 排除主营业务缺乏竞争力的公司
- 再叠加动态/静态 `PE` 的约束做进一步筛选

讲师口播里把动态市盈率字段读作 `pcf_ratio`、静态市盈率读作 `pe_ratio`；由于字幕存在转写噪声，具体字段名仍应以量化平台 API 为准。

## 引用与数据

- 市净率公式：每股市价 ÷ 每股净资产。
- 市销率公式：股价 ÷ 每股销售额。
- 课程强调市盈率分动态与静态两种口径：一个偏预测值，一个偏已披露财报值。
- 代码演示里出现的筛选阈值包括：`PB < 1.5`、`PS < 0.5`，以及进一步叠加动态/静态市盈率过滤。
- 口播给出的聚宽字段线索包括：`pb_ratio`、`ps_ratio`、`pe_ratio`，另一个动态市盈率字段的字幕转写存在噪声。
