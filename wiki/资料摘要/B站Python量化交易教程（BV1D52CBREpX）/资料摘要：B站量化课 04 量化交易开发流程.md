> 这讲把量化交易落到工程流程上，给出从数据获取到实盘交易的七步研发链路，并强调策略回测、优化与模拟盘是进入实盘之前不可跳过的迭代环节。

## 核心要点

- 量化交易开发的七个步骤是：数据获取、数据清洗、策略编写、策略回测、策略优化、模拟盘交易、实盘交易。
- 数据层面不仅要获取行情、宏观、财务和舆情数据，还要完成清洗、空值填充、格式转换和多源对齐。
- 策略编写的通用框架是“信号捕捉 - 交易 - 建仓/平仓”，其中信号定义决定策略行为。
- 回测、优化和模拟盘是层层递进的验证过程，讲师明确反对跳过模拟盘直接上实盘。

## 详细笔记

- 数据获取方式包括网站下载、客户端、第三方 API 和爬虫，各有成本、质量和授权差异。
- 数据清洗部分推荐使用 NumPy 和 Pandas，重点处理错误数据、空值、类型和时间对齐问题。
- 回测流程被拆成参数设置、策略实例化、历史数据载入、回测执行、盈亏计算、统计指标计算和报告生成。
- 策略优化时要重视交易费、风险控制和退出机制，并避免为了拟合历史而无限制调参。
- 讲师建议模拟盘至少稳定运行半年且收益表现足够明显后，再考虑实盘；实盘初期则要控制仓位、避免杠杆、重视心态。
