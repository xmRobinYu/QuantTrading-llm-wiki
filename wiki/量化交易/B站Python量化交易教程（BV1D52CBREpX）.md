> 这是一门以 Python 量化交易入门与岗位转型为主题的 B 站长视频课程入口页，当前已确认其导学结构，但 298 集目录尚未完全展开。

## 背景与动机

当前量化知识库已经有概念、研究方法和实盘检查线，但缺一类“面向初学者的视频课程入口”。这门课的价值不在于它一定最严谨，而在于它代表了中文互联网里一种非常典型的量化学习入口：

- 用超长视频压缩入门路径
- 同时覆盖金融、数学、编程三个维度
- 强调转型、实战和就业

因此它适合被纳入知识库，作为“课程型来源”的一个样本入口。

## 核心内容

### 1. 当前已确认的课程结构

根据导学字幕，课程至少覆盖：

- 量化交易行业前景
- 金融与统计前置知识
- Python 量化开发基础
- 技术指标与时间序列分析
- 策略案例与回测展示
- 就业与面试指导


### 2. 公开可见目录结构（69讲）

目前通过 B站公开 `pagelist` 接口，可确认的课程结构如下：

- `01-07`：导学、量化交易基础、开发流程、交易产品、盈利模式、策略信号
- `08-15`：股票基本概念、行业分类、影响股价因素、交易基础、量化思维、择时、量化平台
- `16-21`：`NumPy`、`pandas`、`Matplotlib` 在股价统计、均线、时间序列、K线与技术分析中的应用
- `22-28`：量化策略编写基础，包括核心函数、定时函数、交易函数与策略实战
- `29-32`：量化交易数据获取
- `33-38`：基本面量化选股，包括营收、财务、规模、价值、质量等因子
- `39-46`：量化择时与技术指标，包括 `MACD`、`EMA`、`MA`、`RSI`、`WR`、压力支撑与量价指标
- `47-51`：策略回测与风险指标，包括回测流程、`MACD` 策略和多类风险评价指标
- `52-55`：因子分析与自定义 alpha 因子
- `56-69`：策略实战案例，包括双均线、KDJ、MA-RS、BOLL、新能源、低估值、大小盘轮动、逆三因子等

这套结构已经足以把它定位成“完整的中文量化入门课程骨架”，即使还没逐讲展开正文。

### 3. 与当前知识库的连接点

这门课和知识库现有主树的对应关系很清楚：

- 研究方法层：[[量化研究]]、[[回测]]、[[样本外测试]]

### 4. 当前还没完成的部分

当前已经确认这门课并非公开可见的 298 个分 P，而是 `69` 个公开分 P。也就是说，“298 集”更像标题营销口径，而知识库当前能严格落地的，是 69 讲课程结构。

因此现在这页已经从单纯入口页升级为“有公开目录的课程入口页”，但仍不是逐讲正文都已摄取完成的课程全集页。

## 现状与趋势

这类超长视频课程对知识库的价值，更多是：

- 帮助识别大众入门叙事
- 补中文互联网中的课程型来源
- 为后续做“课程学习路径 vs 实盘研究路径”的对照提供材料

但它的弱点也明显：

- 结构容易冗长
- 深度和严谨性不一定均匀
- 若不继续拆分目录，很难直接复用到细粒度查询

## 开放问题

- 公开可见部分只有 69 讲，剩余“298 集”是否来自站外资料包、隐藏分集或纯营销表述，仍待验证。
- 是否要继续逐讲抓取 69 讲字幕，并拆成更细的课程资料摘要页？
- 是否值得把这类 B 站课程沉淀成一个统一的“视频课程来源”子目录？
