> 本讲把量化策略最小框架拆成初始化与策略函数两部分，并用聚宽示例说明如何把交易想法写成可执行规则。

## 核心要点

- 课程把策略框架浓缩成两部分：`initialize` 负责一次性的初始化，策略函数负责重复执行的交易逻辑。
- `context` 被定义为聚宽中的全局对象，用来保存证券、账户、持仓等策略运行时信息。
- 示例策略的核心思想很简单：若上一时点价格高于五日均价一定比例则买入，低于五日均价则卖出。
- 课程明确指出：量化平台常有自己的 IDE 与 API 体系，策略代码不只是普通 Python 脚本，还依赖平台运行环境。

## 详细笔记

这讲是课程从数据分析迈向“可交易策略”的分界点。前面的 `NumPy`、`pandas`、`Matplotlib` 主要解决算与看，这一讲开始讨论如何让代码真正驱动下单。

初始化部分主要负责设定全局变量，例如股票代码、基准或后续运行函数；它只运行一次。策略函数则是持续被调度的逻辑核心，承担取行情、算条件、下单和记录日志的责任。这个拆分很重要，因为后续所有设置函数、交易函数和账户对象都会围绕这两个入口展开。

课程示例使用聚宽平台的 `order`、价格获取与均线计算接口，展示了一个极简的动量式规则。虽然策略本身很初级，但它清楚说明了量化策略的基本形态：数据输入、条件判断、交易动作。

## 引用与数据

- 课程把策略框架概括为 `initialize` 与策略函数两大部分。
- `context` 被描述为存放股票账户、持仓等信息的全局对象。
- 示例规则围绕“上一时点价格”和“五日平均价”构建买卖条件。
