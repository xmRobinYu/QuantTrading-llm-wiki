> 本讲把市场看成震荡体而不是单向趋势体，因此重点转向超买、超卖和反转信号，核心工具是 `RSI`、`WR` 与 `KDJ`。

## 核心要点

- `RSI` 本质上衡量“向上波动幅度占总波动幅度的比例”，课程给出最直接的阈值是：大于 `80` 超买，小于 `20` 超卖。
- `WR` 的课堂口诀与 `RSI` 方向相反：高于 `80` 偏买入，低于 `20` 偏卖出，强调的是短线行情见底或见顶。
- `KDJ` 仍然是课程最推崇的反趋向指标，原因是它对短期超买超卖更敏感，也更容易写出量化规则。
- 课程明确比较了可编码性：`KDJ` 的阈值和交叉逻辑通常比 `RSI` 的图形形态规则更容易实现。

## 详细笔记

### RSI：相对强弱指标

课程把 `RSI` 解释成：

- `N` 日上涨幅度之和占上涨与下跌总波动之和的比例
- 数值越大，市场越强；数值越小，市场越弱

口播给出的主要应用规则：

- `RSI > 80`：超买，偏卖出
- `RSI < 20`：超卖，偏买入
- `RSI = 50`：多空力量大致均衡

课程也提到诸如 `M` 头、头肩顶、`W` 底等形态，但同时暗示这些图形判断在代码里更难严格定量化。

### WR：威廉指标

`WR` 侧重短线波动区间。课程的重点不是公式推导，而是应用口诀：

- `WR > 80`：市场偏超卖，行情可能见底，偏买入
- `WR < 20`：市场偏超买，行情可能见顶，偏卖出

这套方向与 `RSI` 常见口语理解不同，因此课程专门提醒要单独记忆。

### KDJ：更适合量化实现

课程对 `KDJ` 的评价明显更高，原因包括：

- 比普通均线更敏感
- 对短线超买超卖更友好
- 有多种可以直接转成条件表达式的规则

课堂总结出的易实现规则包括：

- `KD > 80` 时回档概率较大
- `KD < 20` 时反弹概率较大
- `K` 在 `20` 附近上穿 `D`，可视作买点
- `K` 在 `80` 附近下穿 `D`，可视作卖点
- `J > 100` 或 `J < 0` 时，提示反转风险升高

## 引用与数据

- `RSI` 课程阈值：`80 / 20 / 50`。
- `WR` 课程阈值：高于 `80` 偏买入，低于 `20` 偏卖出。
- `KDJ` 演示默认参数：`N = 9`、`M1 = 3`、`M2 = 3`。
- `KDJ` 的 `J` 值阈值：大于 `100` 或小于 `0` 时提示反转。
