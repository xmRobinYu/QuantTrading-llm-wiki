> 把课程里的基本面选股和因子分析压成一页最小速查，帮助快速回答“因子从哪里来、怎么分类、怎么实现、怎么判断结果”。

## 背景与动机

因子章节最容易出现两个问题：

- 概念很多，但记不住哪个因子属于哪一类
- 会写一个因子，但不知道结果该怎么看

课程其实已经把这条线讲通了，只是分散在 `33-38` 和 `52-55` 讲里。这页就是把它压成一张最小研究表。

## 核心内容

### 1. 先记五类基本面输入

- 营收类：同比、环比、营业总收入
- 利润类：净利润同比、环比、营业利润率、销售净利率、销售毛利率
- 规模类：总市值、流通市值、总股本、流通股本
- 价值类：`PB`、`PS`、动态/静态 `PE`
- 质量类：`ROE`、`ROA`

### 2. 因子研究最小流程

按课程 `52-55` 讲，可以先压成四步：

1. 选因子类别
2. 选具体字段或定义自定义因子
3. 跑因子分析结果
4. 判断是否值得进入策略池

### 3. 三个最该记住的问题

#### 因子从哪里来

- 财务字段
- 价格 / 成交量字段
- 自定义组合公式

#### 因子属于哪一类

- 选股语义：成长 / 规模 / 价值 / 质量
- 研究语义：单因子 / 多因子 / Alpha 因子

#### 因子结果怎么看

- 先看有没有信号
- 再看收益质量
- 再看是否只是暴露或噪声

### 4. 课程里最关键的两个桥

- `33-38` 讲负责把财务和估值语言翻译成选股因子
- `52-55` 讲负责把这些因子翻译成研究对象和分析结果

没有前一段，后一段会变成空洞 API；没有后一段，前一段会停留在字段堆砌。
